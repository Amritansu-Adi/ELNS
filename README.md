# ELNS (E-Learning and Notes Sharing)

[![Live Site](https://img.shields.io/badge/Live%20Site-Visit-green)](https://elns-ugte.onrender.com/)


A full-stack MERN (MongoDB, Express, React, Node.js) application designed to help students **share, access, and organize educational resources** such as notes, previous year papers, and study materials in a streamlined, user-friendly interface.

---

## 🌐 Live Demo

🔗 [https://elns-ugte.onrender.com](https://elns-ugte.onrender.com)

---

## 🧩 Features

- 📁 Upload and download **PDF notes**, **question papers**, and **study guides**
- 🔍 Filter by **semester**, **subject**, or **file type**
- 📚 Organized by **courses** and **departments**
- 💬 Clean and minimal **React UI** with intuitive navigation
- 🌙 Dark-themed UI for comfort
- 🚀 Fast performance using Render for hosting

---

## 🛠️ Tech Stack

**Frontend:**
- React.js
- React Router
- Axios
- Tailwind CSS

**Backend:**
- Node.js
- Express.js
- MongoDB (via Mongoose)
- Multer (for file uploads)

**Other Tools:**
- Render (Deployment)
- GitHub (Version Control)
